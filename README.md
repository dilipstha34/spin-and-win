# 🎰 Slot Machine Game

A simple command-line Slot Machine game built with Node.js where players deposit money, place bets, spin the slot machine, and win based on matching symbols.

## Features

- Deposit an initial balance
- Bet on 1–3 lines
- Random slot machine spins
- Automatic winnings calculation
- Balance updates after each round
- Play multiple rounds until you quit or run out of money

## Technologies Used

- Node.js
- JavaScript
- prompt-sync

## Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/dilipstha34/spin-and-win.git
   ```

2. Navigate to the project folder:
   ```bash
   cd slot-machine
   ```

3. Install dependencies:
   ```bash
   npm install
   ```

## Running the Project

```bash
node spinNwin.js
```

## How to Play

1. Deposit an initial amount.
2. Choose the number of lines to bet on (1–3).
3. Enter your bet amount per line.
4. Spin the slot machine.
5. Win if all symbols on a selected line match.
6. Continue playing or quit.
